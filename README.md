# Runtime Riches

Runtime Riches is a terminal quiz about Go. Answer 20 questions to reach the ₦20,000,000 in-game jackpot.

## Run the game

Install Go 1.22.2 or later, then run this command from the repository root.

```sh
go run .
```

Enter your name, then answer with `A`, `B`, `C`, or `D`. Type `HELP` to see the rules or `LIFELINE` to choose 50:50, Hint, or Suggestion. You can use each lifeline once per round.

Correctly answering questions 5, 10, and 15 guarantees the prize at that level if you later answer incorrectly. Type `WALKAWAY` and confirm to keep your current prize. All prizes in this version are fictional. You can start a new round from the result screen.
